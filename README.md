## 🧰 Tech Stack

This project uses the following technologies to provide a responsive, offline-capable, and modern digital RPG experience.

| Technology           | Purpose                                                                 | Documentation |
|----------------------|-------------------------------------------------------------------------|----------------|
| [Next.js](https://nextjs.org/docs)         | Core framework (built on React) for routing, SSR, and frontend/backend integration |
| [React](https://reactjs.org)               | Component-based UI framework (used via Next.js)                                     |
| [Tailwind CSS](https://tailwindcss.com/docs) | Utility-first CSS framework for building UI quickly and responsively                |
| [PostCSS](https://postcss.dev/)            | CSS processor used to run Tailwind and other plugins like Autoprefixer             |
| [Autoprefixer](https://github.com/postcss/autoprefixer) | Automatically adds vendor prefixes to CSS                                          |
| [next-pwa](https://github.com/shadowwalker/next-pwa) | Adds PWA support (offline access, installability) to Next.js apps                 |
| [Dexie.js](https://dexie.org)              | Friendly wrapper around IndexedDB for storing offline data (e.g., character sheets) |
| [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) | Browser-native database for persistent offline storage                            |
| [Web App Manifest](https://web.dev/add-manifest/) | Defines metadata for Progressive Web App (name, icons, launch behavior)            |
| [Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API) | Caches app files for offline use (auto-generated by `next-pwa`)                    |

## 🔧 Optional / Recommended Add-ons

| Tool                   | Use Case                                                   | Documentation |

| [Vercel](https://vercel.com/docs)               | Hosting platform with CI/CD and edge functions (ideal for Next.js) |
